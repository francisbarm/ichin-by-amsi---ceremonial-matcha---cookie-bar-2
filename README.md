# ICHIN By AMSI — Ceremonial Matcha & Cookie Bar

> Experiencia de barra móvil y catering ceremonial de matcha, repostería de autor, bombones artesanales y cotizaciones para eventos corporativos, bodas y celebraciones en Caracas.

---

## 🍵 Descripción del Proyecto

**ICHIN By AMSI** es una plataforma web y de catering de lujo diseñada para presentar el servicio de barra móvil especializada en:
- **Matcha Ceremonial Grado A (Uji & Kioto)**: Bebidas frías y calientes preparadas al momento (Iced Matcha Latte, Vainilla Latte, Coco Frío, Ceremonial Kioto, Strawberry Matcha Cloud, etc.).
- **Cookies y Repostería de Autor**: Cookie Red Velvet AMSI con chocolate blanco, Cookie con Dulce de Leche casero, Double Chocolate Fudge, etc.
- **Bombonería Fina**: Bombones artesanales de chocolate con ganache de matcha, maracuyá y avellana, y trufas de cacao 70%.
- **Cotizador Inteligente para Eventos**: Sistema interactivo para cotizar barras completas según número de invitados, tipo de montaje (Barra Madera Nórdica, Barra Espejo Champán, etc.) y paquete de personalización.
- **Integración Directa con WhatsApp**: Envío de presupuestos y pedidos personalizados directamente al equipo de atención (`+58 414 3260003`).
- **Showcase del Carrito Móvil y Accesorios**: Visualización en vivo de la barra móvil de eventos y personalizaciones disponibles.

## 🚀 Tecnologías

- **Vite** — Build tool ultra rápido.
- **React 19** + **TypeScript** — Componentes tipados y modernos.
- **Tailwind CSS** — Paleta refinada suave (*sage green, matcha cream, warm latte, slate accents*).
- **Lucide React** — Iconografía minimalista.
- **Canvas Confetti & QR Code** — Experiencias interactivas para cotizaciones y vista móvil.

## 💻 Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/francisbarm/ichin-by-amsi---ceremonial-matcha---cookie-bar-2.git
   cd "ichin-by-amsi---ceremonial-matcha---cookie-bar-2"
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   La aplicación se abrirá en `http://localhost:3000`.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
